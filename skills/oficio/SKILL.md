# Oficio

Lente de **construcción**. Cada sub-skill es una checklist: se aplica al texto, no se recita.

Canon en `skills/oficio/`. `.cursor/skills/oficio` y `.github/skills/oficio` son enlaces: editar solo el canon. Rutas de abajo, relativas a `skills/`.

Respuesta en **español**. Hallazgos citan el **relato** (fragmento + hecho), nunca el curso. Las checklists no se vuelcan al chat.

## Mapa

Cargar **solo** las sub-skills que el turno toca.

| Aspecto | Cargar | Quién llama |
|---------|--------|-------------|
| hábitos, método, bloqueo, dar feedback | `oficio/proceso/SKILL.md` | usuario; `sinopsis` (adaptar el grill a jardinero / arquitecto) |
| promesa, progreso, recompensa, arquetipos, esquema, ritmo | `oficio/trama/SKILL.md` | `sinopsis`, `sugerencia-capitulos`, `chapter-editor` §1, §6, §8, §9 |
| modelo de narrador, cabezas, ocultar información | `oficio/punto-de-vista/SKILL.md` | `chapter-editor` §5 |
| sistema mágico, poderes, costes | `oficio/magia/SKILL.md` | `chapter-editor` §4 |
| ambientación, exposición, consistencia | `oficio/mundo/SKILL.md` | `chapter-editor` §3, `build-context`, `contexto-capitulo`, `riso-illustration` |
| diseño de personaje: empatía, escalas, motivación, defecto | `oficio/personaje/SKILL.md` | `chapter-editor` §2, `build-context` (fichas), `sinopsis` (arcos) |
| personaje en la página: diálogo, descripción, introspección, acción | `oficio/caracterizacion/SKILL.md` | `chapter-editor` §2, §5, §7 |
| humor, finales, segunda vuelta, lectores alfa / beta | `oficio/revisiones/SKILL.md` | `chapter-editor` (veredicto y lista de cambios) |

Varios aspectos en un cap: cargar los que el texto toca. Un cap sin magia no carga `magia`.

## Lectores, aparte

`chapter-reader` y `fantasy-reader` leen como público: sensación, no oficio. Esas skills trabajan sin esta lente.

## Fuente

Destilado de apuntes privados en `fuentes_privadas/curso_de_escritura_creativa/temas/` (gitignored). Cada sub-skill nombra su tema. Abrir el tema solo si un check no basta; si falta la carpeta, las checklists valen solas.

Publicar o vender el libro: skill `carrera`, no esta.

## Hecho

Cada sub-skill cargada se aplicó: cada check o tiene hallazgo con cita del relato, o se marca «sin hallazgo».
